# py-xiaozhi Documentation Index

This directory contains all the documentation for the py-xiaozhi project, organized by functional modules for easy reference and use.

The project has the following modules enabled by default: Music, Lighting, Volume, Timer, Home Assistant Controller, and Camera IoT Control. Additional modules can be enabled and extended as needed.  
The Visual Recognition feature requires configuring the API Key for the Zhipu AI model to function.  
The project has adopted the v2 authorization protocol, with the WSS link returned via the OTA interface. Both the official Xiaozhi and open-source backends have aligned their authentication processes.
